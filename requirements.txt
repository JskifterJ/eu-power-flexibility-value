# Python dependencies for eu-power-flexibility-value.
# Installed into a local .venv (gitignored). Appended to as later cycles need
# more (modelling: scikit-learn/lightgbm; LP: highspy/pulp; plots: matplotlib).
#
# C1 (config, Energy-Charts client, cache, manifest):
requests>=2.32
PyYAML>=6.0
pandas>=2.2
numpy>=1.26
pytest>=8.0

# C2 (stitching loader, data contracts, hourly aggregation, price figures):
matplotlib>=3.8

# C3 (walk-forward harness, naive model, leakage guard): no new dependencies —
# pandas/numpy/pytest already cover it.

# C4 (LEAR: per-hour LASSO, in-fold asinh/standardisation, in-fold AIC/BIC/CV
# penalty selection). The floor is 1.7 because LassoCV's alpha-path argument was
# renamed there (`n_alphas` -> an int `alphas`), and forecast/lear.py uses the
# current spelling.
scikit-learn>=1.7

# C5 (battery dispatch LP + MILP). scipy is already present transitively via
# scikit-learn, but C5 depends on it directly so it is declared directly. HiGHS
# ships inside scipy, so there is no separate solver install and no licence:
# `scipy.optimize.linprog(method="highs")` for the LP and `scipy.optimize.milp`
# for the forbid_simultaneous variant. The floor is 1.11 because `milp` and the
# `Bounds`/`LinearConstraint` objects it takes settled into their current form
# there.
scipy>=1.11

# C7 (ENTSO-E client, exogenous loader, manifest + contracts): no new
# dependencies. The Transparency Platform returns XML, parsed with the standard
# library's xml.etree.ElementTree — no lxml, and deliberately no `entsoe-py`:
# the whole point of data/entsoe.py is the explicit refusal behaviour CLAUDE.md
# requires (an Acknowledgement is a FLAG, nothing is retried that should not be,
# nothing unvalidated reaches the cache, the token never reaches disk), which a
# convenience wrapper would hide.

# C8 (exogenous features into LEAR, Tier A, + the RES-forecast degradation
# sensitivity): no new dependencies. The exogenous columns are a join and a
# vintage offset on top of C7's loader, and the model is C4's committed LEAR.

# C9 (the gradient-boosted model: one fixed LightGBM config, in-fold early
# stopping, Tier A only). The floor is 4.3 because `lgb.early_stopping` settled
# into the callback form forecast/gbm.py uses there, and because 4.x is where
# `deterministic=True` became reliable enough to assert bit-reproducibility on
# (tests/test_c9_gbm.py::test_the_fit_is_bit_reproducible). PLAN.md forbids a
# hyperparameter search across cycles, so the committed config lives in
# `forecast.gbm.GbmSpec`, is fingerprinted into every result row, and is pinned
# to literals by a test — a later cycle cannot tune a knob without editing a
# test, which CLAUDE.md makes a flag-and-stop event.
lightgbm>=4.3
